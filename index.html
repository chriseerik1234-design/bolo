Bolo for Windows

Programming that reads like English.

Bolo is a small language for everyday file, text, and desktop-app chores. It was made for people who have never programmed — and it is still useful when you have.

Install with one command

Open PowerShell (press Win, type PowerShell, press Enter), paste this line, and press Enter:

irm https://github.com/chriseerik1234-design/bolo/releases/latest/download/install.ps1 | iex

Windows 10 or 11. No administrator rights. It installs only for you, in %LOCALAPPDATA%\Programs\Bolo, and adds a Start Menu shortcut. Nothing is uploaded.

Or download the zip

Prefer to see the files first? Download, unzip anywhere, and double-click Bolo Learn.bat.

Download Bolo-Windows.zip

Includes the learning app, Bolo Chat, the language, the lessons, and examples.

What you get

Bolo Learn

A window with 18 short lessons, an editor, Run and Check buttons, a playground, and a searchable reference.

Bolo Chat

A local-AI chatbot that talks about anything, with Bolo as its specialty. Chat mode or code mode, your choice.

Bolo Tasks

A working to-do list written entirely in Bolo. Add, finish, and delete tasks; it saves itself and never touches the internet.

A taste of the language

# Show every JPEG in a folder files("photos") |> filter({ ext(it) is "jpg" }) |> each({ say(name(it)) }) # Tables, loops, and values inside text person = table("name", "Mari", "age", 12) person["city"] = "Tartu" for key, value in pairs(person) { say("{key} = {value}") }

Good to know

  • No Python needed. The installer includes everything.
  • No account, no cloud. Your code and progress stay on your computer.
  • The AI is optional. Chat and the tutor use Ollama on your own machine. The language and all 18 lessons work without it.
  • Easy to remove. Start Menu > Bolo > Uninstall Bolo.
